## 需要人類決定的問題
1. forbidigo 的 `os.Create`／`os.WriteFile` 只能限制到 package 層級（`internal/cli/`），無法限定到「輸出函式」。
2. `test/`、`internal/testutil/`、`_test.go` 對 forbidigo 的 I/O、時間、`os.Exit`、`panic` 規則整體排除（`test/e2e/fakegit` 為獨立假 git 程式需 stdout／`os.Exit`）；這同時讓 `test/` 下其他測試輔助碼也不受限。
3. 實際使用 golangci-lint v2.15.0；正式版號由 SRE 於 O-001 決定。
4. 為讓同一行多個 forbidigo 違規都被回報，`.golangci.yml` 加入 `issues.uniq-by-line: false`（預設會每行只留一個，導致驗證方式 #10 只看到 1 個問題）。
5. 因 `internal/cli` 尚不存在，「禁止 import internal/cli」的 depguard 規則本次無法實測（探針只得到 typecheck 錯誤）；archtest 規則 1 已涵蓋。
6. archtest 規則 3（網路）只檢查非測試檔，依任務單；depguard 則連測試檔也禁止。
7. 本機原無 Go，經你同意以 `brew install go` 安裝。
