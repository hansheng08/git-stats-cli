   | `cmd/git-stats` | `internal/cli`、`internal/version` |
   | `internal/cli` | `internal/daterange`、`internal/gitlog`、`internal/stats`、`internal/render`、`internal/model`、`internal/apperr`、`internal/version` |
   | `internal/daterange` | `internal/model`、`internal/apperr` |
   | `internal/gitlog` | `internal/model`、`internal/apperr` |

### lint 規則（`.golangci.yml`）
- `version: "2"`。`run.tests: true`。
- 啟用 linters：`depguard`、`forbidigo`、`errcheck`、`govet`、`staticcheck`、`errorlint`、`gosec`；formatters：`gofmt`、`goimports`。
- **depguard**（與 archtest 互為備援，至少涵蓋）：
  - 全部檔案：禁止 `net`、`net/http` 等網路套件（`$all`，測試檔亦禁）。
  - 非測試檔：禁止 `os/exec`，排除 `internal/gitlog/**`、`internal/testutil/**`。
  - 全部檔案：禁止 import `github.com/hansheng08/git-stats-cli/internal/cli`，排除 `cmd/git-stats/**` 與 `internal/cli/` 自己的 `_test.go`（外部測試 package `cli_test`）。
  - `internal/stats/**`、`internal/render/**`：禁止 import `.../internal/gitlog`，且彼此禁止。
- **forbidigo**（`analyze-types: true`）：
  - `os.Exit`、`log.Fatal*`：只允許 `cmd/git-stats/`。
  - `fmt.Print*`、`os.Stdout`、`os.Stderr`：只允許 `cmd/git-stats/`。
  - `time.Now`、`time.Local`：只允許 `cmd/git-stats/`。
  - `panic`：非測試檔一律禁止。
  - `os.Create`、`os.WriteFile`：只允許 `internal/cli/`（ARCHITECTURE §9 寫「cli 的輸出函式」，lint 只能做到 package 層級，報告中註明）。
  - `_test.go` 與 `internal/testutil/` 排除上述 I/O 類規則（測試需要建檔、計時）；`panic` 規則對它們也排除。
- **gosec**：`G204`（以變數執行子程序）只在 `internal/gitlog/`、`internal/testutil/` 與 `_test.go` 排除，其他地方照常報錯。
- 不得在 `.golangci.yml` 以外用 `//nolint` 放行；本任務不應需要任何 `//nolint`。

## 實作限制（介面、檔案位置、命名、可用套件）
- 只用 Go 標準庫（`go/parser`、`go/token`、`path/filepath`、`io/fs`、`strings`、`testing` 等）；不得新增依賴、不得用 testify。
